While Media over QUIC has generated significant buzz as a next-gen transport protocol, working multi-party conferencing implementations are still rare. hang.live provides a practical proof-of-concept demonstrating that real-time interactive media can bypass the traditional WebRTC stack entirely using WebTransport and WebCodecs. It serves as a valuable open-source reference for engineers looking to study MoQ relay architectures and client pipelines in the wild.
